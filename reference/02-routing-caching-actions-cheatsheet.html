Routing, 4-Tier Cache & Server Actions

Bảng tra cứu nhanh về Parallel/Intercepting Routes, 4 tầng Cache và Server Actions trong React 19.

1. Advanced Routing Patterns

  • Parallel Routes (`@slot`): Render nhiều slots đồng thời trong 1 layout. Cần `default.tsx` fallback.
  • Intercepting Routes (`(.)route`): Chặn điều hướng soft-navigation (Modal view) nhưng giữ full-page trên hard-navigation.
  • Route Handlers (`route.ts`): Web Standard GET, POST, PUT, DELETE. Không để chung `page.tsx`.
  • Middleware (`middleware.ts`): Edge Auth guard, Headers mutation, Redirects.

2. The 4-Tier Caching System

  • 1. Request Memoization: Server in-memory, deduplicate `fetch` trong 1 request lifecycle.
  • 2. Data Cache: Server persistent, cache `fetch` qua nhiều requests. Invalidate: `revalidateTag()`.
  • 3. Full Route Cache: Server HTML & RSC Payload của static pages.
  • 4. Router Cache: Client tab in-memory. Invalidate: `router.refresh()` hoặc `revalidatePath()`.

3. Server Actions & React 19 Hooks

  • `'use server'`: Hàm async chạy ở Server, biến thành HTTP POST Endpoint ngầm.
  • `useActionState`: Quản lý Form state, error messages từ Server Action.
  • `useOptimistic`: Giả lập update UI ngay tức thì trước khi Server phản hồi (auto rollback).
  • Form Security: Bắt buộc Auth Check & Zod Validation bên trong Server Action!

4. State Management Strategy

  • URL State (SearchParams): Single Source of Truth cho Pagination, Search, Filtering.
  • Server State: Quản lý tự động bằng Server Component Fetch & Caching.
  • Client State (Zustand/useState): Chỉ dành cho Transient UI State (Modal, Form draft, Theme).
  • Root Context Pattern: Bọc Provider Client Component trong `app/layout.tsx` Server Component.

Bí Quyết Phỏng Vấn (Senior Cheat-Sheet)

🎯 3 Bẫy phỏng vấn thường gặp:

1. "Xóa item DB xong nhưng trang back lại vẫn thấy?" -> Do Router Cache ở Client Tab. Fix: Call revalidatePath() hoặc router.refresh().

2. "Có nên dùng Prisma trực tiếp ở Edge Runtime?" -> KHÔNG! Edge V8 Worker không có TCP Connection Pool truyền thống, dễ làm quá tải DB.

3. "Tại sao nên đẩy State Search/Filter lên URL?" -> Bookmark được, Shareable URL, và giúp Server Component fetch dữ liệu tĩnh ngay từ Server.
