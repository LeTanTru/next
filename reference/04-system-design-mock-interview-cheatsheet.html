System Design & Live Coding Refactoring

Bảng tra cứu tổng kết cho bài thi phỏng vấn System Design và Live Coding Challenge.

1. E-Commerce Rendering Matrix

  • Home & Category: ISR (`revalidate = 3600`) + Tag-based revalidation.
  • Product Detail: PPR (Static Shell CDN 0ms + Dynamic Stock Hole).
  • Cart & Checkout: Dynamic SSR + HttpOnly Cookies.
  • Dashboard Admin: Dynamic SSR + Granular Suspense Streaming.

2. Infrastructure & Scalability

  • Database Proxy: Bắt buộc dùng PgBouncer / Prisma Accelerate chống sập connection pool khi Serverless scale.
  • Multi-tier Cache: Next.js Data Cache + Redis KV Store.
  • Edge Middleware: Routing, Geo-IP, A/B Testing tại CDN POPs.

3. Checklist Code Refactoring

  • ❌ Bỏ `'use client'` ở Root Page -> Chuyển thành Server Component.
  • ❌ Xóa `useEffect` fetch data -> Chuyển sang `async/await` fetch ở Server Component.
  • ❌ Không đọc `localStorage` -> Đổi sang HttpOnly Cookie.
  • ✅ Bọc phần UI chậm trong `` để triệt tiêu Waterfall.

4. Top Senior Mindset Rules

  • 1. Luôn giải thích **Why & Tradeoffs** trước khi nêu giải pháp.
  • 2. Ưu tiên giữ code trên Server (0KB Client JS).
  • 3. Sử dụng URL làm Single Source of Truth cho State có tính chia sẻ.
  • 4. Bảo mật Secrets với package `server-only`.
