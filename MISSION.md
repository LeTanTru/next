# Mission: Next.js 16 & React 19.2 Interview Mastery (Middle/Senior Level)

## Why
Hệ thống toàn bộ kiến thức sâu, bản chất và tư duy kiến trúc Next.js 16 (Turbopack, Cache Components `"use cache"`, `updateTag` vs `revalidateTag`, `proxy.ts`, Async Request APIs, RSC, Rendering & Performance) để tự tin chinh phục và trả lời xuất sắc các câu hỏi phỏng vấn vị trí Next.js Middle / Senior Frontend / Fullstack Engineer.

## Parallel project
không

## Success looks like
- Trả lời trôi chảy, đúng bản chất và nêu rõ tradeoffs của từng cơ chế trong Next.js 16 (RSC vs Client Components, Cache Components `"use cache"`, `updateTag` vs `revalidateTag(tag, profile)`, `proxy.ts` thay thế `middleware.ts`, Async Request APIs, Streaming, Hydration, Security).
- Giải quyết thành công các câu hỏi bẫy (trick questions) và bài toán thiết kế hệ thống (System Design) cho ứng dụng Next.js 16 quy mô lớn.
- Tự tin thực hành live coding, refactoring và debug các lỗi thực tế (Hydration mismatch, Waterfall fetch, Caching bugs, Memory leaks).

## Constraints
- Không dùng dự án lớn song song — tập trung đi nhanh, học sâu bản chất, các câu hỏi phỏng vấn và bài tập sân tập nhỏ gọn, cô đọng.
- Tất cả bài học đều giải thích rõ VÌ SAO + ĐÁNH ĐỔI, kèm ví dụ code tiếng Việt và trích nguồn chính chủ (Next.js 16 Docs, React WG, Vercel Engineering).

## Out of scope
- Phân tích sâu Pages Router legacy ngoại trừ phần so sánh kiến trúc với App Router và kế hoạch migration.
- Các framework khác ngoài hệ sinh thái React / Next.js.
