# Next.js Interview Mastery Resources

## Knowledge

- [Next.js Official Documentation (App Router)](https://nextjs.org/docs)
  Tài liệu chính thức chính chủ từ Vercel. Dùng cho: Kiến trúc App Router, Caching, Rendering, Routing, Security.
- [React Official Documentation - Server Components & React 19](https://react.dev/reference/rsc/server-components)
  Tài liệu gốc về React Server Components (RSC), Actions, useOptimistic, Suspense. Dùng cho: Bản chất RSC & React Primitives.
- [Vercel Engineering Blog](https://vercel.com/blog)
  Bài viết kĩ thuật sâu từ Vercel về Partial Prerendering (PPR), Turbopack, Edge Runtime, Caching Architecture.
- [React Working Group (RSC Discussions)](https://github.com/reactwg/react-18/discussions)
  Các thảo luận kiến trúc giữa React Core Team & Community về Server Components, Hydration, Streaming HTML.

## Wisdom (Communities)

- [r/nextjs Subreddit](https://www.reddit.com/r/nextjs/)
  Cộng đồng thảo luận các bài toán thực tế, kinh nghiệm phỏng vấn và các edge-cases trong Next.js.
- [Next.js Official Discord Server](https://discord.gg/nextjs)
  Kênh trao đổi kĩ thuật trực tiếp với các Core Maintainers và Next.js Developers trên toàn thế giới.
